# FileForge v0.2.1

FileForge v0.2.1 menyempurnakan Video Toolkit offline di Windows dan Android serta menambahkan Batch Compress.

## Baru di v0.2.1

- Batch Compress: pilih beberapa video sekaligus dan proses antrean satu per satu
- Progress batch keseluruhan
- Counter berhasil/diproses
- Cancel batch
- Windows memilih satu folder output untuk seluruh batch
- Android tetap memakai pendekatan storage yang aman; lokasi output diminta per file agar tidak membutuhkan izin akses semua file

## Video Toolkit

- Compress Video: High Quality / Balanced / Smallest
- Target Size compression berdasarkan batas ukuran MB
- WhatsApp preset: 720p, 30 FPS, H.264 + AAC
- Resize Video: 1080p / 720p / 480p
- Trim / Cut berdasarkan waktu mulai dan selesai
- Change FPS: 24 / 30 / 60 FPS
- Extract Audio ke MP3
- Convert ke MP4
- Remove Audio
- Video ke GIF
- Video Info, progress, cancel, dan FFmpeg log

## Windows

Gunakan `FileForge-Setup-v0.2.1.exe`. Installer membuat shortcut Desktop dan Start Menu serta menyediakan uninstaller.

## Android

Gunakan APK ARM64 untuk mayoritas HP modern atau APK universal untuk kompatibilitas lebih luas. Minimum Android API 24.
